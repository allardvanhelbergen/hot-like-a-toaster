# hot-like-a-toaster

A single-page retro landing site with 1950s diner aesthetic - featuring vintage appliance red and chrome metallic typography.

## Setup

```bash
npm install
npm run dev
```

Visit [http://localhost:4321](http://localhost:4321)

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- **Astro 5.x** - Static site framework
- **Custom CSS** - Chrome text effects, retro styling
- **Google Fonts (Righteous)** - 1950s diner typography
